# 🍎 Frutería del Día

Proyecto final de Desarrollo Web con HTML, CSS y JavaScript.

## Tecnologías
- HTML5
- Tailwind CSS
- JavaScript

## Funcionalidades
- Catálogo de frutas con imágenes.
- Búsqueda de frutas.
- Modo oscuro.
- Carrito con control de cantidades.
- Formulario de contacto con validación.

## Páginas
- `index.html`: página principal.
- `carrito.html`: carrito de compras.
- `contacto.html`: formulario de contacto.

## Ejecución
Abre `index.html` en el navegador. Se recomienda utilizar Live Server en Visual Studio Code.

Proyecto con fines académicos.
